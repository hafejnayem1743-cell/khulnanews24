# Khulna News 24 v9.3

## v9.3 changes
- Preserved all v9.2 fixes and Cloudflare Worker integration.
- Homepage Worker fetch remains at up to 5000 stored items.
- Homepage “latest” section now displays the complete merged published feed instead of showing only a small subset.
- All districts' automatic news appear together on the homepage; district pages remain available as an optional filter/explorer.
- Added a cleaner “সকল সর্বশেষ সংবাদ” heading, live item count, and responsive 1/2/3/4-column news grid.
- Existing article detail page and SocialShare component retained; share controls remain inside each news post with Facebook, WhatsApp, Telegram, X, copy-link, native mobile share and print.
- No Cloudflare Worker source or Cron configuration was changed in this v9.3 package.
