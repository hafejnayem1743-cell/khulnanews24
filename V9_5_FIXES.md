# Khulna News 24 — v9.5

## Included
- Adsterra Banner 728x90 integration in header/home/article banner slots.
- Adsterra Native Banner integration for responsive in-content/sidebar advertising.
- Admin Adsterra manager keeps desktop code + optional mobile code workflow.
