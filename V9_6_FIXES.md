# v9.6 — Advertising & Contact UX Update

- Preserved the v9.5 project architecture and existing features.
- Added the supplied Adsterra 728x90 Banner, Native Banner, Social Bar and optional Popunder codes as canonical default ad slots.
- Kept Popunder disabled by default to avoid an overly aggressive reading experience; it remains available from the admin ad manager.
- Enabled Social Bar globally.
- Kept the single supplied Native Banner in a single active slot because its container ID is fixed and must not be duplicated on the same page.
- Article pages retain controlled top, in-content and bottom banner placements rather than inserting ads after every paragraph.
- Added a polished advertising/contact page at `/contact`.
- The public advertising page does not visibly print the phone number, WhatsApp number or email address. The buttons use the configured Site Settings values for direct phone, WhatsApp and email actions.
- Existing `/contact` navigation from the header is preserved.
- Added v9.6 ad layout polish and responsive overflow protection.
